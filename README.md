# ShopHub 🛒

ShopHub is a full-stack e-commerce web application built as a practical project to understand how a real-world online shopping platform is designed and developed from scratch.

The project covers both customer and admin functionality, including product browsing, authentication, cart management, wishlist, checkout, orders, and product administration.

* User
* Product
* Category
* Cart
* Wishlist
* Order

Relationships between these entities will be designed before implementing the database models.

## 🔐 Authentication & Security

The application will use:

* JWT for authentication
* bcrypt for password hashing
* HTTP cookies where appropriate
* Environment variables for sensitive configuration
* Role-based authorization for customer and admin access
